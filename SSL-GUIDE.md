# SSL Certificate Management Guide

## Overview
All web and Nagios servers are configured with self-signed SSL certificates automatically generated by Ansible.

## Certificate Details

### Web Servers
- **Location**: `/etc/nginx/ssl/`
- **Certificate**: `{{ inventory_hostname }}.crt` (e.g., `node1.crt`)
- **Private Key**: `{{ inventory_hostname }}.key` (e.g., `node1.key`)
- **Validity**: 365 days
- **Key Size**: 2048-bit RSA
- **Subject**: `/C=FR/ST=IDF/L=Paris/O=ITIC/OU=IT/CN={{ inventory_hostname }}.{{ dns_domain }}`

### Nagios Servers
- **Location**: `/etc/nginx/ssl/`
- **Certificate**: `nagios.crt`
- **Private Key**: `nagios.key`
- **Validity**: 365 days
- **Key Size**: 2048-bit RSA
- **Subject**: `/C=FR/ST=IDF/L=Paris/O=ITIC/OU=Monitoring/CN={{ nagios_server }}`

## Accessing HTTPS Services

### Web Servers
```bash
# Accept self-signed certificate with -k flag
curl -k https://node1
curl -k https://node2.dev.local

# View certificate details
openssl s_client -connect node1:443 -showcerts
```

### Nagios Web Interface
```bash
# Access Nagios (credentials: nagiosadmin/nagiosadmin)
curl -k -u nagiosadmin:nagiosadmin https://node4/nagios4/

# From browser (ignore certificate warning)
https://node4
https://nagios.dev.local
```

## Verify SSL Certificates

### Check Certificate Details
```bash
# On web server
ansible node1 -i inventory.ini -b -m shell -a "openssl x509 -in /etc/nginx/ssl/node1.crt -text -noout | grep -A2 Subject"

# On Nagios server
ansible node4 -i inventory.ini -b -m shell -a "openssl x509 -in /etc/nginx/ssl/nagios.crt -text -noout | grep -A2 Subject"
```

### Check Certificate Expiration
```bash
# Web server certificate
ansible '*_web' -i inventory.ini -b -m shell -a "openssl x509 -in /etc/nginx/ssl/\$(hostname).crt -enddate -noout"

# Nagios server certificate
ansible '*_nagios' -i inventory.ini -b -m shell -a "openssl x509 -in /etc/nginx/ssl/nagios.crt -enddate -noout"
```

### Verify Nginx SSL Configuration
```bash
# Test Nginx configuration
ansible '*_web' -i inventory.ini -b -m shell -a "nginx -t"
ansible '*_nagios' -i inventory.ini -b -m shell -a "nginx -t"

# Check SSL/TLS protocols
ansible node1 -i inventory.ini -b -m shell -a "grep ssl_protocols /etc/nginx/sites-available/*"
```

## SSL Security Features

### Implemented Security Measures
1. **TLS 1.2 and 1.3 only** - Older protocols disabled
2. **Strong cipher suites** - HIGH security ciphers
3. **HTTP to HTTPS redirect** - Automatic upgrade to secure connection
4. **Security headers**:
   - `X-Frame-Options: SAMEORIGIN`
   - `X-Content-Type-Options: nosniff`
   - `X-XSS-Protection: 1; mode=block`
   - `Strict-Transport-Security` (HSTS)
5. **Server tokens hidden** - Version information not exposed
6. **SSL session caching** - Performance optimization

## Regenerate Certificates

### Manually Regenerate (on target node)
```bash
# Web server
cd /etc/nginx/ssl
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout node1.key \
  -out node1.crt \
  -subj "/C=FR/ST=IDF/L=Paris/O=ITIC/OU=IT/CN=node1.dev.local"
chmod 600 node1.key
systemctl restart nginx

# Nagios server
cd /etc/nginx/ssl
openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout nagios.key \
  -out nagios.crt \
  -subj "/C=FR/ST=IDF/L=Paris/O=ITIC/OU=Monitoring/CN=nagios.dev.local"
chmod 600 nagios.key
systemctl restart nginx
```

### Using Ansible (Recommended)
```bash
# Remove existing certificates and re-run playbook
ansible node1 -i inventory.ini -b -m file -a "path=/etc/nginx/ssl/node1.crt state=absent"
ansible node1 -i inventory.ini -b -m file -a "path=/etc/nginx/ssl/node1.key state=absent"
ansible-playbook -i inventory.ini web.yml --limit node1

# Or re-run for all
ansible '*_web' -i inventory.ini -b -m shell -a "rm -f /etc/nginx/ssl/*.crt /etc/nginx/ssl/*.key"
ansible-playbook -i inventory.ini web.yml
```

## Testing SSL/TLS

### Test with OpenSSL
```bash
# Test TLS connection
echo | openssl s_client -connect node1:443 -brief

# Check supported protocols
nmap --script ssl-enum-ciphers -p 443 node1

# Verify certificate chain
openssl s_client -connect node1:443 -showcerts < /dev/null
```

### Test with curl
```bash
# Verbose SSL handshake
curl -kvI https://node1

# Check HTTP to HTTPS redirect
curl -I http://node1
```

## Troubleshooting

### Certificate Issues
```bash
# Check if certificates exist
ansible node1 -i inventory.ini -b -m shell -a "ls -la /etc/nginx/ssl/"

# Verify certificate and key match
ansible node1 -i inventory.ini -b -m shell -a "openssl x509 -noout -modulus -in /etc/nginx/ssl/node1.crt | openssl md5"
ansible node1 -i inventory.ini -b -m shell -a "openssl rsa -noout -modulus -in /etc/nginx/ssl/node1.key | openssl md5"
```

### Nginx SSL Errors
```bash
# Check Nginx error logs
ansible node1 -i inventory.ini -b -m shell -a "tail -50 /var/log/nginx/error.log"

# Check SSL-specific logs
ansible node1 -i inventory.ini -b -m shell -a "grep SSL /var/log/nginx/error.log"

# Test configuration syntax
ansible '*_web' -i inventory.ini -b -m shell -a "nginx -t"
```

### Browser Trust Issues
Self-signed certificates will show warnings in browsers. To trust them:

1. **Firefox**: Add security exception
2. **Chrome**: Type `thisisunsafe` when viewing certificate warning
3. **Production**: Use Let's Encrypt or proper CA-signed certificates

## Production Considerations

For production environments, consider:

1. **Let's Encrypt** - Free, automated, trusted certificates
2. **Certbot** - Automated certificate management
3. **Certificate monitoring** - Alert before expiration
4. **Proper DNS** - Valid domain names
5. **Load balancers** - SSL termination at edge
