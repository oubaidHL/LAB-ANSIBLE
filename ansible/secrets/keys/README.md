# SSH Keys Directory

This directory contains SSH keys used for Ansible automation.

## Files

- `id_rsa` - Private SSH key (never share this!)
- `id_rsa.pub` - Public SSH key (safe to distribute)

## Generation

Keys are automatically generated by the `push_key.sh` script in the parent directory.

## Manual Generation

If you need to regenerate keys manually:

```bash
ssh-keygen -t rsa -b 4096 -f secrets/keys/id_rsa -N "" -C "ansible@lab"
```

## Security

- Private key permissions should be `600` (read/write for owner only)
- Public key permissions should be `644` (readable by all)
- Never commit private keys to version control
- These files are ignored by git (see .gitignore)
